SeeItLive for Odoo

See what your customer sees, live, from inside Odoo.

Send a customer a link from any contact, lead or task. They open it on their phone and share their camera — no app, no account — and the agent watches, annotates and takes snapshots without leaving the record.

How it works

1. Open a record

A contact, a CRM lead, a task — click the SeeItLive tab.

2. Send the link

By SMS, by email, or copy it yourself. A QR code is there too, for handing over in person.

3. Watch, live

The customer's camera opens right inside the record. Annotate it and take snapshots as you talk.

Key features

  • A three-state panel embedded in the form: launcher, waiting room, live view
  • Works on any model with a chatter — contacts, leads, tasks, and beyond, your choice
  • SMS, email, or link-only invitations, with an explicit consent gate for SMS
  • Optional guest protection: a password or a rotating code
  • Snapshots land back on the record as attachments automatically
  • A chatter note summarises every finished call, even if the agent's tab closed early
  • HMAC-SHA256 request signing, opt-in per API key
  • Sandbox indicator when using a test API key (sil_test_*)

Configuration

  1. Create a SeeItLive account and generate an API key.
  2. In Odoo: Settings → SeeItLive, paste the key and click Test connection.
  3. Pick your defaults — invite channel, invite lifetime, guest protection — and which models get the tab.
  4. Open any enabled record and start a live view.

Data & privacy

This module only talks to SeeItLive when an agent explicitly starts a session. That request sends the recipient's phone number or email address (for the channel chosen) and which Odoo record and database the session belongs to. Nothing else leaves Odoo — not the record's other fields, not its chatter history. See the module's README.md for the full privacy statement.
